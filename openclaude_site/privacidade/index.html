🔒 Política de Privacidade

Última atualização: 28 de Abril de 2026

1. Informações Gerais

O OpenClaude é um sistema que opera localmente no computador do usuário. Não coletamos, armazenamos ou compartilhamos dados pessoais de usuários finais em servidores externos.

2. Dados Processados

O Sistema processa exclusivamente:

  • Dados públicos de plataformas: Métricas de vídeos públicos (views, likes, comentários) obtidos via APIs oficiais do YouTube, TikTok e Instagram
  • Credenciais de API: Chaves e tokens armazenados localmente no arquivo .env do usuário
  • Conteúdo gerado: Roteiros, áudios, imagens e vídeos criados pelo Sistema ficam armazenados localmente

3. Armazenamento

Todos os dados processados pelo OpenClaude são armazenados exclusivamente no computador do usuário, nas pastas data/ e logs/ do projeto.

4. Compartilhamento

O OpenClaude não compartilha dados com terceiros. A única comunicação externa é feita diretamente com as APIs oficiais das plataformas (YouTube, TikTok, Instagram) para fins de:

  • Busca de tendências e métricas públicas
  • Publicação de conteúdo nas contas do usuário

5. Direitos do Usuário

Por ser um sistema local, o usuário tem controle total sobre seus dados:

  • Visualizar: todos os dados estão nas pastas do projeto
  • Excluir: basta deletar as pastas data/ e logs/
  • Exportar: os dados estão em formatos abertos (JSON, CSV, TXT)

6. Cookies e Rastreamento

O OpenClaude não utiliza cookies, trackers ou qualquer forma de rastreamento de usuários.

7. Contato

Dúvidas sobre privacidade? Abra uma issue no GitHub do projeto.
