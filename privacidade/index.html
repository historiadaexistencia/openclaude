Política de Privacidade do OpenClaude

Este aplicativo não coleta, armazena ou compartilha dados pessoais de usuários finais.

Os dados processados são exclusivamente de conteúdo público das plataformas (YouTube, TikTok, Instagram) para fins de análise de tendências e criação de conteúdo automatizado.
